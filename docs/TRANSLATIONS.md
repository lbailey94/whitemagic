# Translations

Community translations of the quickstart. They are deliberately
**version-free**: the README (and the release manifest) carry the current
version, so translations never rot between releases. Commands, route names,
and JSON stay identical in every language.

is community-translated and machine-assisted; native-speaker review is
invited — open a PR or say so in an issue.

## Help wanted

More languages welcome — and native speakers reviewing the translations that
landed on 2026-10-01 are especially welcome. See the translation bullet in
[`CONTRIBUTING.md`](../CONTRIBUTING.md).

To add one:

1. Copy a translation and translate the prose — leave commands, route names,
   and JSON blocks untouched.
2. Add the language switcher line at the top (linking all translations).
3. Add the row to the table above and a line to the README documentation
   index.
4. Open a PR. Native speakers reviewing another translation are especially
   welcome — say so in the PR and we will route it.
