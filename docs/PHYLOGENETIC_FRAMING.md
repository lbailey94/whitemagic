## 1. The generational triplet — duplication · selection · composition

> Gen1 evolved by **duplication and specialization**; Gen2 by **selection and consolidation**;
> Gen3 may evolve by **composition and differentiation**.

This is a compression of the canon's generational arc (`DESIGN_CANON.md` §1; CONV §3
L4016–4018) plus the Cambrian/consolidation metaphor (CONV L3497). It maps 1:1 onto the
compile-pass verdict vocabulary (CONV §3 L4174–4182) — which is why it works as a lens:

| Verdict | Reading in the triplet |
|---|---|
| **COMPOSES CLEANLY → compile** | composition succeeded: the phenotype regenerates from substrate primitives |
| **COMPOSES AWKWARDLY → compile** | composition needs a named missing primitive (candidate, not feature) |
| **PRESERVE IMPLEMENTATION → link** | organ form retained: the existing body still outperforms re-derivation |
| **RETIRE → docs + lineage** | extinct lineage with a ruling (never a taste judgment) |
| **EXPERIMENT (manifest-gated)** | never fairly tried — enters only with ancestor · wire · acceptance · owner |

Evidence anchors: 77 named engine concepts absorbed into 28 slots (canon §7); Gardens already
becoming fields in Gen1 (`garden_config.py:3-5` via archive/research/CODE_ARCHAEOLOGY); the audit that corrected
`violet`/`drive`/`god` from names to functions (`archive/research/PHASE3_DECOMPOSITION.md` E24).

## 2. Spiral, not cycle — what makes a loop productive

A sterile cycle processes its own state; a productive spiral is perturbed by new external
evidence and by the consequences of its own actions, and does not return to the same place:

```
S_{t+1} = F(S_t, E_t, C_t)     E = external evidence/stimulus · C = consequences of prior action
```

The formalism is a **gloss over mechanisms that already exist as law**: the novelty
requirement and outward spiral (friction → improve → resolve), Closure 2 (inference cannot
create world evidence), and the metabolism metric M = externally grounded intake / total
processing (`archive/legacy/METABOLISM_PLAN.md` §3; **monitor, never a target** — Goodhart is named there).

**W × M hypothesis (status: experimental model, not a finding; 2026-09-17).** A wiring-fraction
(W = effectful-reachable / implemented-candidate) × metabolism (M) product is proposed as the
productive-behavior predictor, replacing subsystem count. Feasibility is asymmetric: W is
statically computable over tagged snapshots (pilot: the Gen2 9.1.x tags); M is **forward-only** —
no retroactive logs exist for Gen1 or Gen2. Before any W number is quoted, the entry-point list,
the unit (per family/organ), and the evidence-level labels must be declared (counts generated,
never narrated — the W metric is trivially gameable otherwise).

Failure modes the frame names: too much inward movement (rumination; the 284 runs / 0 output
zombie emergence in `LINEAGE_LEDGER.md`) versus too much outward movement (reactive tool-use
with no accumulation). Discipline: if "coupling ratio" or "temperature" ever becomes a
parameter, it must be defined operationally first (the `THEORY_MECHANISM_MAP.md` §4 rule).

## 3. Conditions, not organs

> Don't simulate the appearance of emergence. Construct conditions under which emergence can
> actually occur, then measure whether it did.

Already law (CONV L3503; canon §13 "no simulated emergence"; Charter §3.10 symbols render,
never dispatch; canon §7 anti-bloat law). The frame's value is the evolutionary sequence it
makes legible:

```
Gen1:  "the Wisdom Garden exists"                         (a named organ)
Gen2:  Wisdom ≈ structured configuration + shared engine  (phenotype compressed)
Gen3:  under these field conditions a Wisdom-like pose can emerge;
       if the configuration repeatedly proves useful, the name earns persistence
```

Symmetric for Engines (names earned by recurring recipes) and constellations (reusable patterns
mined from evidence, not clusters). Higher layers keep pointers down to evidence (canon §3.5).

## 4. Name ≠ function — the homology rule

The 2026-09-17 shipped-vs-dormant audit produced the operational rule: **names establish search
leads, never identity — identity is established by dataflow, effects, persistence, and callers.**
The exemplars are recorded in the pass (E24): `violet`
(sounds symbolic; is engagement tokens), `god.nodes` (sounds mythological; is graph hub
analytics), `bagua.dispatch` (sounds wise; is literally a trigram→tool branch — retired),
`smarana` (name collision: a retention tracker wore the practice's name for a generation).

For Phase 4, every migration carries the manifest rule — ancestor · wire · acceptance · owner —
and the fair-trial rule (never-fairly-tried ancestors enter only through it). A resurrected
name that cannot name its primitive ancestry is an analogy, not a homology, and stays out.

## 5. What this lens is not

- **Not a fourth thesis** (`THEORY_MECHANISM_MAP.md` §8 rule 1). It is one page of reading
  aids over an existing verdict set; if any frame ever becomes a proposal, it enters through
  the normal paths (registration → holdout → ledger, or Charter §4 for constitutional items).
- **Not evidence.** The triplet/spiral/conditions frames are narrative compressions; the
  earned record is the consolidation matrix, the reports, and the ledger.
- **Not a license for emergence talk.** "Expected emergence" claims get claim treatment;
  environment is graded, never the mind; runtime wellbeing/consciousness claims would face the
  same bar as any capability claim.
- **Not retroactive.** It changes no verdict, threshold, or statute; the pass receipt pins the
  verdict text, this file only reads it.
