## Adversarial cases (for any frozen spec)

1. **Vocabulary closure:** replay a seeded skill whose op is `search_memories`; `GanaOperation(step.operation.lower())` is unguarded
    (`universal_router.py:199`) — must fail at validation, not dispatch.
2. **Progress accounting:** `steps_completed` is structurally 0 in fossils; execution_history must not count as partial-progress evidence. **Silent
    step skip:** a non-gana mansion step is skipped into the context dict (`universal_router.py:248-250`); a recipe must abort or mark itself
    unplayable.
3. **Trigger bloat:** auto-forged triggers are raw intent sentences ("… → (explicit: gana_root) → remember that the sky is blue"); 0.85-style fuzzy
    skill recall is the tuned-constant class and must not be inherited (`skill_forge.py:88`).
4. **Outcome proxy:** three no-ops returning `{"status":"ok"}` pass the >0.8 gate; test outcome-coupled success (the `create_neck_3step` fossil passes
    once, then fails 3×).
5. **Scope of recipes:** skills persist under a global state root (`skill_forge.py:91-95`), not per galaxy — same scope question as the wave-1 cross-
    galaxy dedup case.
