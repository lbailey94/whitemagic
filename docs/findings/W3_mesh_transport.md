## 2. Selection history

## 5. Adversarial cases

1. **Legitimate key rotation = identity theft under TOFU.** A key change for a bound peer is dropped (`transport.rs:1186-1194`); only explicit release/trust-decay paths recover (containment vectors 12-14). Rotation without release must never be silently accepted.

2. **Dual-verify migration window.** `verify_signature_all_eras` accepts the legacy `peer_id:tcp_addr:timestamp` payload whenever `public_key_hex.is_some()` (`transport.rs:186-196`) — a captured pre-9.1.8 signed beacon could replay inside the freshness window. Test the one-release retirement deadline.

3. **Unsigned RPC after authenticated discovery.** A LAN attacker who can open TCP (no handshake) sends well-formed JSON-RPC; only lock calls are credential-gated (`transport.rs:762-777`). Test whether chat/read/mail accept unauthenticated senders.

4. **Semantic pass-through (gate 2 absent).** A verified, unquarantined peer can inject content into chat/read; quarantine judges standing, not meaning (`peer.rs:184-191`).

5. **Clone-swarm conflation.** Clone throughput is single-process FFI search (`clone_army.py:148-176`), never inter-agent transport; a spec citing it as mesh evidence must show a wire, and comment targets are not measurements (omnibus:2764).

## 6. Ablation ideas


1. **Signed-only ingest off** (accept keyless hints for bound peers): expect registry pollution/redirect exposure; the F-4 guard drops exactly these (`transport.rs:1213-1232`).

2. **Replay cache disabled**: captured beacons re-enter as fresh peers; watch `record_verified` verdict paths (`transport.rs:1166-1226`, `replay.rs`).

3. **Quarantine disabled**: containment vectors 9-14 must flip in `ContainmentReport::fully_contained` (`containment.rs:44-47`).

4. **Transport feature off**: single-node mode; mesh tools still register and must fail with the node-absent error, not silently no-op (`mesh_tools.rs:30,374-387`).

5. **Gen1 fallback probe**: without `whitemagic_rs.unified_zodiac_deploy` the Python path degrades to 50 clones/sec/core (`unified_zodiac_army.py:229-231`) — targets are comments, not capability.
