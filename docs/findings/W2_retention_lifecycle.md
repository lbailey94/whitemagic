## Observed behavior

- **Two organs, one name.** `core/memory/mindful_forgetting.py` (498 lines) holds the multi-signal
  `RetentionEngine`; `core/memory/lifecycle.py` (496 lines) runs it from dream/homeostasis;
  `core/memory/memory_lifecycle.py` (205 lines) holds backend decay primitives (`root_modules/lifecycle.py`
  is a legacy scorer imported only by a test).
- **Five signals** (`mindful_forgetting.py:165-171`, `DEFAULT_EVALUATORS`):
  1. `_semantic_signal` (:87) — `importance` (+0.15 for LONG_TERM/PATTERN/IMMUNE), weight 1.0;
  2. `_emotional_signal` (:101) — `max(|emotional_valence|, emotional_weight)`, weight 0.8;
  3. `_recency_signal` (:113) — `0.5 ** (days_since_recall / max(half_life_days, 1))` +
     `min(0.3, ln(1+recall_count)*0.05)`, weight 0.9;
  4. `_connection_signal` (:131) — `min(1, (n_links/10) * avg_strength)`, 0.1 when linkless, weight 0.7;
  5. `_protection_signal` (:145) — hard override (`is_protected|is_core_identity|is_sacred|is_pinned`),
     score 1.0 with weight 100; weight 0 otherwise.
  The module docstring advertises "pattern relevance" as signal 5 (:7-12); the shipped evaluator is
  protection — name ≠ function inside one file. The ancestor matrix prints the shipped form
  ("Sem/Emo/Rec/Conn/Prot×100").
- **Composite and verdicts** (`mindful_forgetting.py:236-256`): weighted mean over signals with
  weight > 0 (0.5 fallback when all weights are 0); `protect` if any protection score ≥ 1.0;
  `keep` if composite ≥ 0.35; `decay` if ≥ 0.15; else `archive`. Thresholds are constructor defaults
  (:211-218); `set_thresholds` mutates them at runtime (:347-359) — no declared, versioned policy surface.
- **Sweep actions** (`mindful_forgetting.py:269-332`): evaluate `um.list_recent(limit=5000)` (:286);
  `decay` → in-memory `mem.decay()` (:316); `archive` → in-memory `neuro_score × 0.5` (:320) plus
  `batch_archive_to_edge(ids, galactic_distance=0.90)` on the backend (:330-332). Docstring: "No memory
  is ever deleted — archived memories are rotated to the galactic edge, not destroyed" (:273-274).
- **Per-memory decay** (`unified_types.py:190-205`): `neuro_score × 0.5**(days_since_recall/half_life_days)`,
  floor `min_score=0.1`; `half_life_days` default 30 (:99); state bands derived from `neuro_score`
  (`MemoryState`, :25-33); `Memory.recall()` pins protected memories (:175-188).
- **Backend semantics** (`core/memory/sqlite_backend.py`): `archive_to_edge` writes distance,
  `neuro_score×0.3`, metadata `archived_at` + `archive_reason='galactic_rotation'` (:1165-1188);
  `delete()` is deprecated and redirects to archive (:1190-1199); the batch variant persists distance
  only (:1241-1261); `update_retention_score` writes `retention_score` + `last_retention_sweep` (:1212-1220).
- **Orchestrated run** (`core/memory/lifecycle.py:160-275`): retention sweep (:174-179), galactic
  `full_sweep` (:192-198, re-persisting distance + retention score via `galaxy_router.py:705-716`),
  `decay_drift` (:202-208 — +0.005 per call for >14-day-inactive memories, cap 0.95, protected immune:
  `galactic_map.py:304-359`), association decay (:210-216).
- **Association decay is the one deletion** (`memory_lifecycle.py:76-176`): episodic edges
  `w·e^(−0.0231·days)` (30-day half-life), semantic edges `w·(1+0.1·days)^−0.5`; edges below 0.05 are
  `DELETE`d (:141-164). Manual `prune_associations(min_strength=0.3)` hard-deletes too (:178-205).
- **What actually ran the sweep in v26** — three call sites: the tool route `memory.retention_sweep`
  (`registry_defs/unauthored_memory.py:117`; `dispatch_memory.py:95` → `cyberbrain.py:118-139`); dream
  phase DECAY (`dream_cycle.py:1047-1059` → manager `run_sweep`); homeostatic low-energy correction on a
  worker thread (`homeostatic_loop.py:436-452`). The slow-lane auto-hook in the docstring is never
  armed: `MemoryLifecycleManager.attach()` (:125-147) has no caller and `LifecycleConfig.auto_attach`
  (:46) is never read (`rg "auto_attach|add_post_flush_hook"` → definition/docstring sites only).
  The maturity gate only instantiates the engine (`maturity_gates.py:184-193`).
- **Dream TRIAGE auto-archive** (`dream_cycle.py:424-459`): `importance<0.2 AND access_count<2 AND
  galactic_distance<0.6 AND is_protected=0 AND neuro_score<0.3`, LIMIT 30 → distance to
  `clamp(+0.15, 0.7..0.8)` + metadata `archive_reason='dream_triage'`; no delete.
- **Rotation is observable in retrieval**: FTS orders by `fts.rank + galactic_distance` ASC
  (`search_commands.py:163`); fallback orders by distance ASC (:184); `UnifiedMemory.recall` pulls
  distance inward `×0.95` (`unified.py:539-546`).
- **Two dead seams**: `fusions.py:1318-1349` `lifecycle_dream_trigger()` imports a module-level

  batch evaluation whose only persisted products in v26 are `galactic_distance`, `retention_score`,
  `last_retention_sweep`, and metadata timestamps — the per-signal breakdown (`RetentionVerdict.to_dict`,

  The fixed Phase-1 `persistent` tier remains the live expression until earned (E5).

## Adversarial cases

1. **Protection dominance.** Protection contributes `score=1.0, weight=100` only when flagged, and
   forces `protect` regardless of other signals (:145-162, :245-247). A corrupt memory marked sacred
   is unreachable by any sweep; test flag-clear → re-sweep paths separately.
2. **Silent signal loss.** Evaluator exceptions are swallowed and the composite renormalizes over the
   surviving signals (:229-242) — a systemic field problem (missing links, bad `half_life_days`) moves
   scores with no event and no journal entry. Test with a poisoned memory object.
3. **Coverage cap.** Tool/dream sweeps evaluate only `list_recent(limit=5000)` (:286); staler memories
   are reached only by the galactic `full_sweep` pagination (`galactic_map.py:204`). Test the same
   store at 4,999 vs 5,001 rows.
4. **Backend mismatch (persist path).** `sweep(persist=True)` calls `backend.batch_archive_to_edge` /
   `batch_update_retention_scores` (:330-332); only `SQLiteBackend` defines them (`sqlite_backend.py:1222,1241`).
   `UnifiedMemory.backend` is `GalaxyAwareBackend` (`unified.py:115-120`), whose only batch operation is
   `batch_update_galactic` (`galaxy_router.py:705-716`). With any archive verdict the call raises; the
   manager catches it and substitutes an all-zeros report (`lifecycle.py:178-190`) — success with
   `evaluated=0`, nothing persisted (UNVERIFIED whether any shipped flow used a raw `SQLiteBackend`).
5. **Wall-clock replay.** Verdicts depend on `days_since_recall` and `datetime.now()`
   (`mindful_forgetting.py:115-126`; `unified_types.py:202`) — replaying a frozen store later changes
   outcomes; a frozen behavioral spec must pin or inject the clock.
6. **Edge pruning outruns memory rotation.** `prune_associations(0.3)` deletes edges 6× stronger than
   the decay floor ever prunes (0.05) — structure loss has a coarser manual path than memory loss
   (`memory_lifecycle.py:141-164` vs :178-205).

## Ablation ideas

- Sweep on/off → measure retrieval-order shift attributable to `galactic_distance`
  (`search_commands.py:163,184`) and recall's inward pull (`unified.py:539-546`); expect no effect on
  rows already at distance 0.
- Replace the 4-signal composite with `importance + recency` only → diff archived sets and ranks
  (quantifies what emotional/connection contribute).
- Freeze `decay_drift` only → isolate drift's share of edge-ward movement vs composite-driven rotation.
- Freeze the evaluator set (no exception swallowing) → measure the renormalization effect.
- Disable association decay/prune → edge-count growth + retrieval effect (Hebbian half parked per E6).
